## Motion
Use Framer Motion with smooth luxury easing: [0.16, 1, 0.3, 1]
Preferred: staggered headline reveal, subtle image entrance, scroll reveal, gentle scale/parallax, CTA micro-interaction, hover preview, one signature transformation animation.
Avoid bounce, excessive 3D, floating random objects, animated gradients everywhere.
